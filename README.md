# overwatch-guide

守望先锋第一视角录像复盘工作台。导入录像，标出想看的时段，得到按交战整理的画面证据、操作建议、教练出处与下一局练习。三份手工示例可以直接浏览，覆盖国王大道温斯顿、多拉多士兵：76 和漓江塔安娜。

## 一次复盘的全过程

1. 在「复盘工作台」导入第一视角录像，或输入六位回放代码。
2. 填写英雄、地图、职责、攻防和本局关注点。
3. 选择开始、结束时间和采样间隔。
4. 点「开始复盘」，等分析跑完。
5. 在报告里逐条看点评，点缩略图回看原画面，导出 Markdown。

三份示例在工作台页面的「示例复盘」一栏，点开就是一整份报告。

## 导入录像

「复盘工作台」支持拖入和点选两种方式。MP4、WebM 直接可用，MOV 取决于其中的编码。导入后工作台会读取时长、截一帧做预览，并从文件名里取英雄和地图，例如 `温斯顿-国王大道.mp4` 会填好这两项。

英雄、地图、职责和攻防都可以留空。留空时工作台会从画面里辨认，认出什么就填什么，你可以随时改。

「本局关注点」写这一局想弄清的问题，比如「分析 A 点每一轮进场的落位，以及屏障该何时交」。这段文字会进到模型的提示里，直接影响点评的针对性，写具体比写「提升意识」有用得多。

## 用回放代码关联录像

输入六位回放代码后，工作台会读取这局的已收录资料：地图、双方英雄、来源链接与核验状态。本机存有同代码的录屏时，弹窗里可以直接打开它并开始复盘；没有的话，点「选择本地录像」把自己录的片段关联上去。

拿到录像的办法：游戏内进入「生涯概况 → 历史记录 → 回放 → 导入」，切到你的视角，录制想分析的时段。

## 设定复盘范围

开始时间、结束时间默认覆盖整段录像。只想看某个点位、某一次团战时，把区间收到那几十秒即可。

采样间隔决定看的密度：

| 间隔 | 适合 |
| --- | --- |
| 4 秒 | 常规复盘，看整体节奏和落位 |
| 2 秒 | 团战细看，看进场、集火和撤离 |
| 1 秒 | 抠技能交换和走位 |

间隔越密，提交的画面越多，费用越高。每次调用带 8 张带时间戳的画面，工作台按这个批量向后推进。

## 读报告

报告按交战分组，每组下面是具体的观察点。每条观察点包含：

- **动作**：这一帧里可核对的画面，例如「贴着左侧墙推进，身前没有掩体」。
- **建议**：下次在什么条件下怎么做。
- **分类**：落位、技能、集火、团战、撤退、视野。
- **把握**：清晰或有限，取决于画面本身能支持到什么程度。
- **出处**：关联的教练笔记或机制卡，点开能看到原文链接。
- **缩略图**：点一下，播放器跳到对应时间。

报告开头的总结收束首要改进或做得好的决策，末尾给出下一局能核对的练习项。

右上角可导出 Markdown，用作自己的复盘记录或发给教练。

## 中断与继续

暂停、关闭页面、服务限流都会保住已写入的片段。重新打开这一局，按钮变成「继续分析」，点它就从上次的位置往后跑。继续时使用原来的模型；换模型先点「重置进度」。

## 教练知识库

启动库有 12 张资料卡，分三类：

- **观摩索引**：人上人老王、Guxue 的专题课，用来寻找观察角度。
- **教练笔记**：Spilo、mL7 等来源里可核对的要点。
- **英雄机制**：英雄本身的技能数据和判定。

每张卡保留作者、原始链接、适用英雄、职责和复盘问题。地图专属的开局思路只在匹配到该地图时参与检索。

「添加教学资料」可以手工录入，也可以粘贴原文、字幕或笔记，由当前模型提炼成一条原则和一个复盘用法。提炼出的摘录会与原文核对，你审核确认后才会入库。之后这张卡会参与同英雄、同职责、同地图对局的检索。

## 模型设置

在「模型设置」里选服务商、填写模型 ID 和 API Key：

| 服务商 | 常用模型 ID |
| --- | --- |
| OpenAI | `gpt-4.1-mini` |
| 通义千问 · 北京 / 新加坡 | `qwen3-vl-plus` |
| DeepSeek | `deepseek-v4` |
| 自定义 · OpenAI 兼容 | 你的网关或本机模型名 |

选「自定义 · OpenAI 兼容」时填接口地址，写到 `/v1` 为止，例如 `https://your-gateway.com/v1`。本机模型服务用 `http://127.0.0.1:11434/v1` 这样的地址即可。

填写后点「测试视觉连接」，工作台会发一张小测试图确认通路，成功后保存。模型 ID 以服务商控制台里的名称为准。

密钥只存在当前页面内存，刷新后重新输入。服务商和模型 ID 会记住，下次打开直接接着用。

## 复盘记录

录像、预览图、分析进度、报告和自建知识卡保存在当前浏览器里。同一台设备、同样的浏览器和站点地址，下次打开就能接着看。清空站点数据会一并移除这些记录。

报告保存了当时的引用快照，之后修改或删除知识卡，旧报告里的出处保持不变。
