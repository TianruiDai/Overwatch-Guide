# ADR 0002：镜像阵容按队记录

## 状态

已接受（2026-11-17）

## 背景

既有 `normalizeRosters` 会从敌方名单删除与己方同名的英雄，便于旧 UI 展示，但不适于镜像对局与换人边界判读。

## 决策

- 交接记录中 `lineups[]` 按回合与时段保存双方英雄，允许同名英雄分属不同队。
- 换人写入 `swaps[]`：`team`、`from`、`to`、`last_old_s`、`first_new_s`，看不清的边界保留 `null`。
- 旧 normalize 行为保留于 legacy 路径；v2 判读与 handoff 校验不再去重敌方镜像名。

## 后果

- 检索与点评需结合 `player` 与 `team` 上下文，不能假定名单全局唯一。
- 需用镜像、换边、观战切镜夹具回归阵容归属。
