# 术语速查

| 术语 | 含义 |
| --- | --- |
| **知识单元** | 教学中一条可检索的决策规则：谁在什么条件下做什么，对应蒸馏产出的一张卡及其主张（claims）。 |
| **证据** | 可跳转的出处片段：教学字幕/画面、本局帧或音轨、官方段落等，用稳定 ID 串联卡片与报告。 |
| **交接（handoff）** | `overwatch-read-match` 交给复盘的结构化对局记录：`source`、`player`、`rounds`、`lineups`、`evidence`、`fights` 等。 |
| **决策点评** | 针对单次团战或决策点的复盘输出：动作、结果、可行替代与依据，可再汇总为教练长文。 |
| **版本事实** | `version` 类卡与官方机制陈述；教学卡通过 `depends_on_cards` 引用，解释时需对齐补丁与适用范围。 |
| **skill 注入** | 服务端按阶段装入对应 skill 正文与引用，模型输出再由宿主契约校验后写入存储。 |
| **双时间轴** | 本局引用（`match_id` / `evidence_id` / 秒数）与教学引用（`bundle_id` / `card_id` / 原课定位）分开存储与渲染，避免混点。 |
