# 守望先锋对局视频判读

先交代玩家用谁、跟谁一队、对面是谁，以及这个阶段要争什么目标。再说明双方实际上怎么打。每个答案都要能定位到一段素材。

## 看片与定位

1. 以用户指定的玩家、片段和问题为范围。把上传视频的播放进度作为主时间轴，显示为 `mm:ss` 或 `hh:mm:ss`。局内倒计时单列。多段视频保留片名，剪辑跳切、回放重复和时间偏移单独标记。
2. 能看视频时先通看，标记出生室、第一次交火、记分板、阵亡回放、换视角、换边和目标转换。只有本地文件时可用 [抽帧脚本](scripts/sample_frames.py) 查看原分辨率画面。先用稀疏帧找位置，再重看每个关键动作的前一刻、动作和后果。用户要求逐秒时，按该密度看指定区间；冷却变化、控制、击杀归属等需要时再看相邻帧。
3. 对回放先认视角归属。用玩家名、观战名牌、记分板所在队与 HUD（抬头显示）绑定被复盘者。阵亡回放、精彩镜头、自由镜头和临时切到队友的画面分别记。敌我始终相对被复盘者。颜色经过队名、名牌或记分板校准后再使用。
4. 录像、单张截图、玩家补充、回放元数据和旧点评分别标来源。只拿到部分帧时照样分析可见的区间。若只有回放码，使用实际可用的回放接入读取它能返回的内容；只返回地图或阵容时就先给这些，说明哪段动作仍需视频。

## 怎样认出英雄、地图和攻防

身份与地图必须按下面五步顺序判断，不许跳步，不许猜测。读不清就留空并请求补帧。

项目把第一人称关键区域裁成带 `region` 标签的图片：`weapon`（武器/双手/准星）、`abilities`（技能栏）、`hud`（左下角玩家 ID）、`bars`（顶部双方英雄条）、`full`（整帧地图与目标）。

| 步骤 | 判断对象 | 只看哪些区域 | 硬性规则 |
| --- | --- | --- | --- |
| 1 | 视角归属 | `full` | 只有第一视角可作玩家英雄来源。观战、阵亡回放、第三人称、Tab 覆盖层时玩家英雄留空。 |
| 2 | 玩家英雄 | `weapon`、`abilities` | 只认本人武器、双手、准星与技能图标。**禁止**用英雄条、击杀栏、队友头像反推。 |
| 3 | 玩家队伍色 | `hud`（左下角） | 读玩家名与头像边框，得到 `blue` 或 `red`。本人颜色 = 我方。看不清写 `unknown`。 |
| 4 | 双方阵容 | `bars`（英雄条） | 逐格读每行最多 5 人。与本人同色的一行是我方，另一行是敌方。镜像对局允许同名；玩家英雄必须在我方且不得写入敌方。 |
| 5 | 地图、模式与攻防 | `full` | 优先地图标题，再用目标 HUD 与地标。攻防按本人颜色那一侧的「进攻/防守」提示判断。 |

### 证据与易混

每条结论都要写证据：区域名 + 画面里看到的文字或图形（例如「abilities 区域 4 号技能为不朽装置」）。只有轮廓或局部特效时标「推断」并写依据；看不清保留「未辨认」，继续判断其他字段。

易混英雄必须区分：西拉≠索杰恩；D.Va≠D.Mon；巴蒂斯特≠雾子；卢西奥≠朱诺；卡西迪≠艾什；黑百合≠半藏。

用户补充的英雄、地图或时间可校正对应记录，并保留「玩家说明」的来源。

## 怎样判整体打法

以一次连续交战为单位。双方重新集结、交战线重置、目标切换或回合结束时划分下一段。跳一次、放一次盾可以是同一波里的两次决策。每波尽量给出下面几项。

- **谁从哪儿打谁**。标记接战前双方站位、先动的一方、切入路线、第一落点、目标及跟进者。注意高台、拐角、侧线、队友能否接上火力或治疗。
- **什么改变了交战**。按先后写实际出现的屏障、位移、控制、保命技能、击杀或撤退，以及谁获得高台、射线或目标进度。写能看到的响应，队内意图单列为推断。
- **打法如何成立**。反复从不同角度机动接近同一目标，可归纳为协同切入；保持距离用多条射线逼退对手，可归纳为远程消耗；借掩体缩短距离并集中近战，可归纳为近身推进。分别给己方与敌方的动作依据，必要时用普通动词描述混合打法。英雄组合可以提示可能的计划，实际执行看画面。
- **归纳到哪一层**。单人上二楼可写「玩家转高台施压」；队友同步进场才支持「全队协同切入」。归纳全片时引用有代表性的不同时间点，说明哪次换人或目标变化改变了打法。单波素材只评价这一波。

## 输出与交接

先用一句话交代玩家、地图/模式、回合及目标。随后按需给三项，一屏短片可合并呈现。

1. **双方阵容**。按时间列「己方（标出玩家）｜敌方｜换人或缺位｜时间与依据」。能辨清时按重装、输出、辅助排列。
2. **关键团战**。列「录像区间｜阶段/目标｜己方动作｜敌方回应｜可见结果」。关键决策写到秒；每段末尾再概括其打法。
3. **整体判断**。给出有画面支持的主要打法、变化点和必要的未确认项。只问身份或地图时直接回答所问内容。

继续做知识库复盘时，在当前上下文传递片名、秒数、回合/目标、视角、阵容变化和团战证据。接入 Agent 或用户指定 JSON 时采用 [交接格式及国王大道示例](references/handoff.md)；普通对话直接给可读结果。
